# Creative Design Portfolio - Kshitiz Singh

This is a premium, creative, and highly simplified portfolio website for Kshitiz Singh, focusing exclusively on:
1. **About Me & Experience**
2. **Creative Poster Designs Gallery**

---

## ⚡ Key Features

- **Luxury Theme**: High-contrast dark background (`#09090B`) with custom purple, blue, and cyan backdrop gradient orbs.
- **Glassmorphic Cards**: Premium blurred panels with subtle border highlights.
- **Custom Cursor trailing**: Tailored glow dot tracking pointer movements.
- **Card Tilt Math**: Mathematical rotation of contact elements based on coordinates.
- **Dynamic Masonry Layout**: Displays uploaded posters in a staggered responsive grid.
- **Interactive Lightbox**: Dynamic zoom, fullscreen transitions, subtitle titles, and keyboard navigation (Left/Right Arrows, Escape).
- **Expandable Uploads**: A toggle uploader to add more designs directly inside the browser.

### Method A: Vercel CLI (Recommended - Fastest)

Vercel is a free, high-performance static hosting platform. You can deploy this site in under 60 seconds:

1. Open your terminal/PowerShell.
2. Navigate to this directory:
   ```bash
   cd C:/Users/DELL/.gemini/antigravity/scratch/kshitiz-portfolio/
   ```
3. Run the following command:
   ```bash
   npx vercel
   ```
4. Follow the prompt instructions (type `y` to confirm, hit Enter to select default configurations, and sign in if requested).
5. Once done, Vercel will instantly output your live production URL (e.g. `kshitiz-portfolio.vercel.app`)!

### Method B: Netlify Drop (Easiest - No Code)

Netlify is another top free static host. You don't need any terminal commands for this:

1. Open your browser and go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Locate this folder on your computer:
   `C:/Users/DELL/.gemini/antigravity/scratch/kshitiz-portfolio/`
3. Drag the entire `kshitiz-portfolio` folder and drop it into the upload box on the Netlify webpage.
4. Netlify will host the site instantly and generate a live URL for you!

### Method C: GitHub Pages

If you track your work on GitHub:

1. Create a new repository on GitHub named `kshitiz-portfolio`.
2. Initialize Git locally in this directory:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of simplified creative portfolio"
   ```
3. Add the GitHub remote URL and push:
   ```bash
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/kshitiz-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In your GitHub repository settings, scroll to **Pages**, select **Deploy from a branch**, choose the `main` branch, and click **Save**.
5. Your site will be hosted live at `https://YOUR_GITHUB_USERNAME.github.io/kshitiz-portfolio/`!
